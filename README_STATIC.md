# 🌐 超星学习通自动化工具 - 静态网页版本

## 🎯 项目特点

这是一个**静态网页版本**的超星学习通自动化工具，具有以下特点：

- 🌐 **无需注册** - 每位访客都有独立的配置空间
- 🔒 **会话隔离** - 每个用户的配置完全独立
- 🔄 **自动重置** - 刷新页面会重置所有设置
- 📱 **响应式设计** - 适配各种设备屏幕
- ⚡ **即时可用** - 打开网页即可使用

## 🚀 快速开始

### 访问方式
1. **本地运行**：`streamlit run streamlit_app.py`
2. **在线部署**：一键部署到Streamlit Cloud

### 使用步骤
1. 🌐 打开网页
2. ⚙️ 在左侧配置参数
3. 🔍 点击"验证配置"
4. 🚀 点击"开始执行"
5. 📊 实时查看进度

## 🏗️ 架构设计

### 静态网页特性
```
用户访问 → 独立会话 → 临时配置 → 执行任务 → 会话结束
    ↓           ↓           ↓          ↓         ↓
  无需注册   session_state  内存存储   实时处理   自动清理
```

### 技术栈
- **前端**：Streamlit Web界面
- **后端**：Python核心API
- **配置**：基于会话的临时存储
- **部署**：支持本地和云端部署

## 🔧 配置管理

### 会话配置特点
- ✅ **临时存储** - 配置仅在当前会话有效
- ✅ **用户隔离** - 不同用户配置互不影响
- ✅ **自动重置** - 刷新页面恢复默认设置
- ✅ **即时生效** - 配置更改立即生效

## 🌍 部署选项

### 本地部署
```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
streamlit run streamlit_app.py
```

### Streamlit Cloud部署
1. Fork仓库到GitHub
2. 访问 [Streamlit Cloud](https://share.streamlit.io/)
3. 选择仓库并配置主文件为 `streamlit_app.py`
4. 点击Deploy

### 其他平台部署
- **Vercel**：支持Streamlit应用
- **Heroku**：通过Docker部署
- **自建服务器**：使用nginx反向代理

## 🛠️ 开发说明

### 项目结构
```
chaoxing/
├── streamlit_app.py        # 🎯 主应用入口
├── api/
│   ├── static_config.py    # ⚙️ 静态配置管理
│   ├── web_adapter.py      # 🔌 Web适配器
│   └── ...                # 其他API模块
├── requirements.txt        # 📦 依赖列表
├── .streamlit/
│   └── config.toml        # ⚙️ Streamlit配置
└── README_STATIC.md       # 📖 本文档
```

### 核心模块
- **static_config.py**：静态配置管理，基于会话
- **web_adapter.py**：Web适配器，桥接UI和API
- **streamlit_app.py**：主应用，提供Web界面

### 扩展开发
- 添加新的配置项：修改 `SessionConfig` 类
- 添加新的功能模块：在 `api/` 目录下创建
- 自定义界面样式：修改 `.streamlit/config.toml`
